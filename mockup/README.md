# BurgerFlow — interfaz

Esta carpeta contiene las pantallas HTML/CSS/JavaScript originales y su navegación. La interfaz mantiene el diseño BurgerFlow y consume `/api` cuando la sirve el backend.

Para ejecutar el prototipo completo, sigue las instrucciones de la [guía del repositorio](../README.md). Abrir `index.html` con `file://` o publicarlo solo en GitHub Pages no proporciona autenticación, API ni persistencia SQLite.

Las pantallas por rol no constituyen una barrera de seguridad: las operaciones protegidas se autorizan en el servidor.
