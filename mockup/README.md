# BurgerFlow

Mockup navegable de un sistema de gestión para restaurante.

## Abrir localmente

Abre `index.html` en un navegador. No requiere instalación ni servidor para revisar las pantallas y la navegación.

## Pantallas

- Panel principal
- Panel de cajero POS
- Carrito y confirmación
- Gestión de inventario
- Menú de clientes
- Monitor de cocina KDS
- Panel de delivery
- Dashboard del vendedor
- Personalización de hamburguesa

Las pantallas comparten la navegación definida en `navigation.js`.

## Evidencia de arquitectura

Consulta la [lámina visual del árbol de componentes y flujo](arquitectura-componentes.svg), que incluye responsabilidades, datos de entrada, reutilización, flujo entre tres vistas, una duda de arquitectura y una respuesta para un compañero.

## Publicar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube el contenido de esta carpeta.
3. En `Settings > Pages`, selecciona `Deploy from a branch`.
4. Selecciona la rama `main` y la carpeta `/ (root)`.

La página principal será `index.html`.
